# 日光與夜色

- 提供頁首「夜色／日光」按鈕，按鈕文字表示切換後的模式。
- 日光：暖米白底（#f0e8da）、燕麥色面板（#e7ddcc）、灰藍文字；夜色：深藍灰底、霧藍與淡紫感的亮色文字。
- 頁首導覽置於獨立圓角色塊框，頂部留出 48–80px 空間，避免文字貼近頁面最上緣。手機導覽在框內另排一列。
- 預設跟隨系統配色，並監聽系統主題變更；手動切換後保存偏好。此次更新不沿用舊版固定日光時期的儲存值。
- 同源分頁的偏好同步；清除偏好後回到跟隨系統。
- 儲存受限時仍可切換，但可能無法跨次造訪保存。
- 主題腳本在樣式前執行；手動切換時，新配色從按鈕中心以羽化圓形遮罩暈開，約 1500ms（1.5 秒）完成。
- 使用 View Transition 保留前後畫面；不支援時退回 650ms 色彩漸變。減少動態效果模式直接切換。
- 動畫期间忽略重複點擊，避免快照重疊；結束時不透明區覆蓋視窗最遠角落。
- 按鈕支援鍵盤與螢幕閱讀器，點按區域至少高 44px。
- 後續作品照片與影片保留原色，不套用整頁反相效果。
- 黑夜模式有低亮度流星背景，暈開完成後依序滑入並停住，不持續循環。
- 流星隨捲動進度小幅視差位移，使用被動事件與單次畫面更新，日光模式不更新背景位置。
- 減少動態效果模式保留靜態流星，停用滑入與捲動位移；手機減少流星數量。
- 日光背景改為右上方透出的雲隙光，移除落葉；使用純白扇形光束與淡灰藍雲層。
- 首次日光載入與切回日光時，光束以 1.8 秒依序展開、淡入，雲層輕微散開；捲動時各層緩慢錯位。減少動態效果時保持靜態。
- 日夜背景互斥，使用不可點擊、對輔助工具隱藏的背景圖層，不影響作品原色。
