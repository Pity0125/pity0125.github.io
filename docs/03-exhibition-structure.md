# 互動展覽：作品分類提案

依已提供的七種作品類型，先規劃四個展區。分類是初步提案，看到實際作品後可調整。

| 展區 | 類型標籤 | 展示重點 |
| --- | --- | --- |
| 視覺編排 | 編排 | 頁面順序、字體層級、版面細節與完整成品 |
| 互動體驗 | App、遊戲 | 操作流程、畫面錄影、設計思考與自己的負責範圍 |
| 光影紀錄 | 攝影、影片 | 攝影系列、影片播放、創作意圖與製作分工 |
| 立體與空間 | 模型、3D 場景 | 多角度照片、場景細節、製作過程與空間概念 |

## 導覽方式

- 首頁：個人介紹與少量精選作品，讓面試官快速認識創作特色。
- 完整展區：提供「全部」與四個展區入口，每張作品卡顯示具體類型。
- 七種類型可作為細部篩選；作品數少時先不增加第二層操作。
- 年份、工具與課程作為作品資訊；有需要才增加篩選。
- 每件作品只維護一份內容，可加上多個類型標籤，避免跨類作品重複建檔。
- 一件遊戲若也有 3D 場景，依主要展示目的決定展區，再以標籤補充。
- 模型已確認為 3D 模型，與 3D 場景同屬立體與空間；部分作品規劃 Sketchfab 預覽。

## 素材整理

公開素材仍依作品名稱存放在 `public/assets/projects/<project-slug>/`，不依展區搬動；未來改分類不會影響路徑。
每件作品的文字放在 `content/projects/<project-slug>.md`，可複製既有範本。

## 下一步需要的內容

1. 已收到首批作品名稱與素材概況，詳見 `../content/project-inventory.md`；接下來取得實際素材。
2. 已選定 PCCS 排版為精選，其餘精選待選。
3. 就讀科系與目標職位（尚未確定也可先留白）。
