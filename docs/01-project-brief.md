# 網站方向討論

## 已確認

- 用途：面試用個人作品集。
- 希望有個人特色，並有豐富的動畫與互動。
- 先完成檔案管理與基本架構，再一起討論主題風格。
- 主題：互動展覽。
- 視覺偏好：日系、透明感、貓頭鷹。
- 展示範圍：大學期間作品，包含編排、App、攝影、遊戲、模型、3D 場景、影片。

- 目標職位與產業：
- 希望面試官記住的三個特質：
- 各類作品數量、作品名稱與精選作品：待補充。
- 網站語言：繁體中文／英文／雙語。
- 個人名稱、聯絡方式與履歷公開範圍：

## 視覺設計提案（細節待討論）

- 以米白、霧灰與淡水藍建立日系透明感，使用留白、細線與半透明面板。
- 貓頭鷹作為展覽嚮導；造型尚未決定，可探索簡約線條或柔和插畫。
- 互動可包含入口揭幕、作品進場、分類切換與詳情展開。
- 首頁精選作品搭配完整展區；分類提案見 `03-exhibition-structure.md`。

## 預定內容架構

首頁介紹 → 精選作品 → 作品詳情 → 關於我 → 聯絡與履歷。

## 動畫原則

- 讓動畫協助引導閱讀、回應操作與說明作品。
- 面試官能快速找到作品、角色與成果。
- 不強迫等待片頭，不接管正常捲動。
- 手機與鍵盤操作也能取得完整內容；避免只有滑鼠移入才可見的資訊。
- 尊重減少動態效果設定，測試時留意低效能裝置。
