# 個人作品集網站

目前階段：基本架構完成，準備討論主題、求職方向與作品內容。

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可看到準備中的頁面。目前使用 HTML、CSS 與 JavaScript，無須安裝套件。正式風格與互動需求確定後，再決定是否需要加入框架或動畫套件。

## 資料夾分工

| 位置 | 用途 |
| --- | --- |
| `index.html` | 網頁入口與主要區塊 |
| `src/styles/` | 色彩、字型、版面與動畫樣式 |
| `src/scripts/` | 頁面互動與動畫行為 |
| `public/assets/images/` | 網站用的個人照、背景與共用圖片 |
| `public/assets/projects/` | 各作品的封面、截圖與展示素材 |
| `public/assets/videos/` | 已壓縮、可公開播放的影片 |
| `public/assets/fonts/` | 有授權的網站字型 |
| `public/assets/icons/` | 圖示與網站 favicon |
| `public/downloads/` | 確定可公開下載的履歷與文件 |
| `content/` | 個人介紹、作品故事與文案草稿 |
| `docs/` | 網站規劃、風格討論與素材管理規則 |
| `source-materials/` | 原始檔、未壓縮照片與參考素材；不公開 |

## 接下來的順序

1. 確認面試職位、希望呈現的個人特質與風格。
2. 整理 3–6 件重點作品，寫出問題、自己的角色、過程與成果。
3. 設計首頁與作品頁，再建立一致的動畫語言。
4. 完成手機版、鍵盤操作、減少動態效果與效能檢查。
5. 檢查素材授權與公開範圍，打包網站並上線。

現在尚未發布網站。未來發布時，只包含 `index.html`、`src/` 與 `public/`；不要直接公開整個工作資料夾。`.gitignore` 不等於網站發布的排除設定。
